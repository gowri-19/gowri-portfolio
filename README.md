## ✨ Features

- **Home:** Personal introduction, profile photo, availability status, and quick navigation.
- **About Me:** Introduction, background, and interests with interactive hover effects.
- **Technical Arsenal:** Overview of programming languages, frameworks, and development tools.
- **Selected Projects:** Showcase of projects with descriptions and repository links.
- **Get In Touch:** Contact section with an interactive code-editor-inspired form and social links.
- **Theme Toggle:** Switch between light and dark modes.
- **Interactive Animations:** Smooth transitions and engaging hover effects.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Resume Download:** Option to download my resume in PDF format.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later recommended)
- npm (included with Node.js)
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/gowri-19/gowri-portfolio.git
```

**2. Navigate to the project directory**

```bash
cd gowri-portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local URL**

Visit the URL displayed in your terminal, usually:

```text
http://localhost:5173
```

### Production Build

To create an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## ⚙️ Customization

You can customize the portfolio by modifying the following:

- **Personal Information:** Update your name, introduction, email, and social links in `src/data.js`.
- **Projects:** Add or modify project details and repository links.
- **Resume:** Replace `public/resume.pdf` with your latest resume while keeping the same filename.
- **Appearance:** Modify colors, typography, layouts, and animations in the CSS files.
- **Contact Form:** Configure an email service such as EmailJS or Formspree if required. Keep API keys and secret credentials in environment variables and never commit them to GitHub.

## 🚀 Deployment

This portfolio can be deployed using [Vercel](https://vercel.com/).

1. Import the GitHub repository into Vercel.
2. Configure the project using the default Vite settings.
3. Click **Deploy**.
4. Once deployment is complete, add the generated website URL to the Live Website section above.

Future pushes to the connected `main` branch can automatically trigger redeployment.
